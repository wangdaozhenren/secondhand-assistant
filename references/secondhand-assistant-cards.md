## L1 常识卡（10 张）

### [L1] 二手手机成色怎么分

- **一句话结论**：99 新=几乎无痕在保；95 新=轻微痕迹；9 新=明显划痕；8 新=明显磨损但功能完好。
- **依据/来源**：二手平台通用成色分级。

## L4 实操卡（7 张）

> 通用经验，非官方标准。

### [L4] 手机验机实操步骤

- **一句话结论**：查序列号→查外观→测功能→查锁→试暗病。
- **步骤**：
  1. 查序列号：官网查激活/保修/型号；
  2. 外观：屏幕纯白/纯黑查坏点漏光；边框磕碰；
  3. 按键/触控：四角触控、电源音量键；
  4. 摄像头：拍照录像对焦；
  5. 通话/录音/扬声器；
  6. Wi-Fi/蓝牙/充电；
  7. 退出原账号、关闭查找；
  8. 电池健康截图。
- **常见错误**：只看外观不测功能。
- **适用边界**：复杂验机走平台验机服务。
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 砍价话术

- **一句话结论**：先查行情，指出瑕疵/配件不全，合理出价不恶语。
- **步骤**：
  1. 先查同款成交价；
  2. 指出可砍点（划痕/过保/无配件）；
  3. 出一个略低于心理价的价；
  4. 卖家拒绝就走，不纠缠；
  5. 成交坚持平台交易。
- **常见错误**：一上来对半砍。
- **适用边界**：—
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 面交防骗流程

- **一句话结论**：公共场所→当面验机→确认无误再确认收货→不先转账。
- **步骤**：
  1. 约公共场所（麦当劳/银行网点/商场）；
  2. 全程机器不离手；
  3. 当面跑验机清单；
  4. 查 ID 锁已退；
  5. 确认无误再平台确认收货。
- **常见错误**：当着卖家面先转账。
- **适用边界**：—
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 卖家上架描述怎么写

  1. 写清型号/容量/颜色；
  2. 购买渠道与在保情况；
  3. 成色如实描述；
  4. 瑕疵特写拍照；
  5. 配件清单；
  6. 不夸大不隐瞒。
- **常见错误**：只发美图不拍瑕疵。
- **适用边界**：—
- **标注**：通用经验。

### [L4] 旧机数据清除步骤

- **一句话结论**：备份→退出账号→关闭查找→恢复出厂→插卡验证。

  3. 关闭"查找我的手机"；

  5. 重启到激活界面即清干净。
